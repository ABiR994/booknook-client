# BookNook

**BookNook** is a small online library: add a book, borrow a book, return a book.

- **Live site:** _add your Vercel URL here after deployment_

## Tech stack

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
